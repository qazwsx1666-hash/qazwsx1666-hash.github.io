## 계산 기준

- **물타기**: 새 평단가 = (q₀p₀ + q₁p₁)/(q₀+q₁). 역산 수량 q₁ = q₀(p₀−t)/(t−p₁), 역산 단가 p₁ = (t(q₀+q₁) − q₀p₀)/q₁.
  본전 상승률 = (새 평단가 − 현재가)/현재가. 수수료·세금 미반영(안내 문구 표시).
- **월 배당**: 세전 연 배당 = 목표 월 배당×12 ÷ (1−0.154), 필요 투자금 = 세전 연 배당 ÷ 배당수익률.
  적립 기간은 월말 납입·연 성장률 월 복리로 1,200개월까지 시뮬레이션. 배당소득세 15.4%(소득세 14% + 지방소득세 1.4%).
- **복리**: 월 실효수익률 r = (1+연수익률)^(1/12)−1, FV = P₀(1+r)ⁿ + C((1+r)ⁿ−1)/r (월말 적립).
  단리 비교는 초기금 전 기간 + 적립금 잔여 기간 단리로 계산. 배증 기간은 ln2/ln(1+r).
- **매도가**: 매수 총액 = 매수가×수량×(1+수수료율). 매도 실수령 = 매도가×수량×(1−수수료율−거래세율).
  본전/목표/손절 매도가 = 투자원금×(1±r) ÷ (수량×(1−수수료율−거래세율)), 1원 올림.
  거래세(2026년 시행 탄력세율): 코스피 0.20%(거래세 0.05%+농특세 0.15%), 코스닥 0.20%, 코넥스 0.10%, 비상장 0.35%.
- **ISA·연금**: 세액공제 = (min(연금저축,600만) + min(IRP,900만), 합산 900만 한도) × 공제율(총급여 5,500만 이하 16.5%, 초과 13.2%, 지방소득세 포함).
  ISA = 원금×(1+r)^n, 일반계좌 세금 = 수익×15.4%, ISA 세금 = max(0, 수익−비과세한도)×9.9% (일반형 200만 / 서민형·농어민형 400만).

> 고배당기업 배당 분리과세(2026년 지급분부터, 2,000만 원 초과 14~30%)와 금융소득 종합과세(2,000만 원 초과)는
> 가이드 본문에서 안내하고, 계산기는 15.4% 원천징수 기준으로 단순화했습니다.

## 원칙

- 제목·H1·키워드에 연도 표기 없음. 페이지마다 고유 title/description/canonical/OG/Twitter, H1 정확히 1개.
- JSON-LD: 모든 페이지 WebApplication + FAQPage (계산기 페이지는 BreadcrumbList 추가).
- 상단 내비게이션은 `.calc-nav` 한 줄(둥근 알약)만 사용.
- 애드센스 스크립트 미삽입(`google-adsense-account` 메타만). `.ad-slot`은 기본 숨김이며 `body.has-ads`를 붙이면 노출됩니다.
- 입력값은 서버로 전송·저장하지 않으며 쿠키·로컬스토리지를 쓰지 않습니다.
- 가이드 본문은 페이지당 1,800자 이상(공백 제외 측정), FAQ 5문항.
