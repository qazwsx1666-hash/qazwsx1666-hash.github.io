## 계산 기준

- **중개보수**: 공인중개사법 시행규칙 별표 1(주택)·별표 2(전용 85㎡ 이하 주거용 오피스텔), 주택 외는 매매 0.9%·임대차 0.8% 협의. 임대차 거래금액 = 보증금 + 월세×100, 합이 5천만 원 미만이면 월세×70.
- **취득세**: 지방세법 제11조(1~3% 누진, 6억/9억 분기)·제13조의2(조정 2주택 8%, 조정 3주택·비조정 4주택·법인 12%, 비조정 3주택 8%), 지방교육세는 일반세율의 10%·중과 0.4% 고정, 농어촌특별세는 85㎡ 초과 시 0.2%/0.6%/1.0%. 일시적 2주택·생애최초 감면(최대 200만 원) 옵션 포함.
- **연말정산**: 근로소득공제(소득세법 제11조), 근로소득세액공제(제59조, 한도 74/66/50/20만 원), 신용카드 등 소득공제(조특법 제126조의2, 최저사용금액 25%, 신용 15%·체크 30%, 한도 300/250만 원 + 자녀 가산), 월세(17%/15%, 1,000만 원 한도, 총급여 8천만 원 이하), 연금저축·IRP(15%/12%, 600/900만 원), 기부금(15%/30%). 4대보험료는 총급여로 추정(2026년 요율). 지방소득세 10% 포함해 환급액 표시.
- **부가세**: 10% 기본, 합계→공급가액은 `round(합계/1.1)` 후 차액을 세액으로.
- **유류비**: 거리÷연비×유가, 1km·100km당, 월·연간.

## 원칙

- 제목·H1·키워드에 연도 표기 없음. 페이지마다 고유 title/description/canonical/OG, h1 1개.
- 상단 내비게이션은 `.calc-nav` 한 줄만 사용(중복 내비 금지).
- 애드센스 스크립트는 미삽입(`google-adsense-account` 메타만 존재).
- 입력값은 서버로 전송·저장하지 않음.
