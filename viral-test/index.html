이렇게 즐기면 더 재밌어요

  1. 혼자 먼저 해보기 — 남에게 보여주기 전에 내 결과부터 확인하세요. 결과 화면에서 유형 이름과 비율이 한눈에 나옵니다.
  2. 결과 요약 복사 — ‘결과 복사’ 버튼을 누르면 유형과 링크가 한 번에 복사됩니다. 카톡·단톡방에 그대로 붙여넣으면 끝.
  3. 친구 결과와 비교 — 링크를 받은 친구는 같은 테스트를 바로 시작할 수 있습니다. 서로 몇 %인지 비교하면 대화 소재가 됩니다.
  4. 링크로 결과 다시 보기 — 공유된 링크에는 결과가 담겨 있어 나중에 다시 열어도 같은 결과 화면이 나옵니다.

결과는 재미를 위한 것이지 진단이 아닙니다. 사람은 상황에 따라 다르게 행동하니, “나는 원래 이런 사람”으로 단정하기보다는 가볍게 웃고 넘기는 정도로 즐겨 주세요.

요즘 이 테스트들이 도는 이유

성향 테스트가 유행하는 이유는 간단합니다. 짧은 질문에 답하는 것만으로 “내 이야기”를 해주기 때문입니다. 에겐·테토는 외모와 말투, 행동에서 풍기는 분위기를 두 갈래로 나눠 친구끼리 서로를 지목하며 놀 수 있게 했고, 직장인 SBTI는 회사에서 겪는 뻔한 상황을 웃픈 캐릭터로 바꿔 스트레스를 웃음으로 돌립니다. 연애 애착유형은 내가 관계에서 왜 그렇게 반응하는지 설명해 주고, 밸런스 게임은 정답 없는 질문으로 취향 차이를 드러내 대화를 만듭니다.

다섯 테스트 모두 로그인 없이 무료로 이용할 수 있고, 응답은 서버로 보내지 않고 브라우저 안에서만 계산합니다. 이름이나 전화번호를 물어보지 않으니 부담 없이 시작하세요.

자주 묻는 질문

모든 테스트가 무료인가요?

네, 다섯 가지 테스트 모두 무료입니다. 회원가입이나 앱 설치, 결제 없이 바로 시작할 수 있습니다.

응답한 내용이 저장되나요?

아니요. 응답은 화면에서 바로 계산되고 서버로 전송되지 않습니다. 사이트를 닫으면 사라지며, 결과 링크에는 유형 정보만 담깁니다.

결과가 마음에 안 들면 다시 할 수 있나요?

결과 화면의 ‘다시 하기’를 누르면 처음부터 다시 시작할 수 있습니다. 기분이나 상황에 따라 답이 달라지면 결과도 달라지니 여러 번 해보셔도 좋습니다.

심리학적으로 정확한 검사인가요?

재미와 자기 이해를 돕기 위한 가벼운 테스트입니다. 전문 진단 도구가 아니며, 애착유형·MBTI 모두 학계에서 논쟁이 있는 개념입니다. 중요한 결정의 근거로 쓰기보다는 대화의 소재로 즐겨 주세요.
